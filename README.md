# Atelier Noir — Premium Interior Studio

A Vite + React implementation of the supplied luxury interior website specification.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Build

```bash
npm run build
```

## Included routes

- /
- /modular-kitchen
- /interior-design
- /home-decor
- /wardrobes
- /portfolio
- /portfolio/:slug
- /gallery
- /about
- /our-process
- /pricing
- /consultation
- /blog
- /contact

## Notes

- Uses React + Vite + Lucide icons.
- Uses remote Unsplash photography placeholders; replace these with licensed brand photography for production.
- Consultation/contact forms are front-end demos and should be connected to a CRM/email/backend before launch.
- WhatsApp number and studio details are placeholders.
